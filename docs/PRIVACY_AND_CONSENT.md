# Privacy and consent

The public consent panel offers Accept optional, Reject optional, and Manage choices. Essential preference storage is always available; analytics and advertising are independently off until consent. Rejecting optional storage never blocks reading. The footer reopens choices.

Google Analytics loads only when a measurement ID exists and analytics consent is true. First-party analytics endpoints reject non-consented events. AdSense loads only with advertising consent, enabled configuration, client ID, and an explicit slot. Production deployments serving regulated regions should replace the local manager with a Google-certified CMP through `WEBNOVEL_CONSENT_PROVIDER`.

Accounts store only operational identity, consent preferences, reader settings, library/progress/history/bookmarks, ratings, and reviews. Security logs should hash IP identifiers. Establish retention, export, correction, and deletion procedures before production. The privacy, cookies, terms, contact, copyright, takedown, accessibility, and about pages are functional and must be reviewed for the actual operator and jurisdictions.
